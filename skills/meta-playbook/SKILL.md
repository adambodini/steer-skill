# Meta playbook: principles v0.1

Status: principles only, to be challenged over time, including by the mentor. No thresholds fixed yet. Every change is logged below with the evidence behind it.
IP rule: generic principles only. No employer data, no agency proprietary models.

## 1. Signal: feed the algorithm the truth
- Optimise to the event closest to money.
- One clean dataset: Pixel + CAPI + app, deduplicated, real-time, rich identity data.
- Click-based attribution over view-through.
- Calibrate against reality with the exit poll multiplier (`exit-poll-attribution`).

## 2. Creative: creative is the targeting
- Volume scales with spend.
- Test in a sandbox, graduate on a fixed weekly cadence.
- Track the core growing (graduation and hold), not launch volume.
- Fatigue is predictable: replace before it hits.

## 3. Media buying: density beats cleverness
- Consolidate so every ad set gets enough signal to learn.
- Three lanes with budget caps: always-on, testing, experiments.
- Bidding earns its way up: volume → cost cap → value.
- Targets are multiplier-adjusted, not platform-reported.

## 4. Offer: a lever, not a constant
- Test offers like creative.
- Match the offer to the customer's buying trigger (JTBD).

## 5. Post-click: the channel owner owns the click to the conversion
- The landing page message matches the ad.
- Find the rate-limiting step (e.g. first-to-second page rate).

## Operating rhythm
- Weekly: graduate and kill.
- Monthly: score each pillar with `channel-standard` (basic / standard / best in class).
- Quarterly: structure review.
